# Nimbus Cloud — Security and Compliance

All data in Nimbus is encrypted in transit with TLS 1.3 and encrypted at rest with AES-256. Encryption keys are rotated automatically every 90 days.

Nimbus holds a SOC 2 Type II report and is certified against ISO 27001. A copy of the current SOC 2 report is available to Enterprise customers under NDA.

Single sign-on using SAML 2.0 is included on the Team and Enterprise plans. Enterprise adds SCIM user provisioning and enforced two-factor authentication for all members of the account.

Audit logging, which records every administrative action with an actor, a timestamp, and the affected resource, is an Enterprise-only feature and logs are retained for 365 days.
